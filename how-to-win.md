# How to win

This file spoils every level. Row 1 is the top row. Column 1 is the left column. Color names match the board.

Mark ruled-out cells with ×. Double-click a cell only when it is the last place an eggplant can be. After each eggplant you find, also mark its whole row, its whole column, the rest of its color, and every cell it touches, including the corners.

## Level 1 — The Beginning

The butter region is the large shape down the left side. Teal is the short vertical pair in column 3. Gold is the small block at the top right. Rose runs down the right side. Blue sits along the bottom.

1. Teal exists only in column 3, on rows 1 and 2. Mark the rest of column 3 with ×.
2. Blue is now only in row 5. Mark the other cells in row 5.
3. Column 1 is now only butter. Mark every butter cell that is not in column 1. That clears column 2 down to a single blue cell.
4. Uncover **row 5, column 2**. It is blue.
5. Row 4 is now only rose. Mark the rose cells outside row 4. Row 3 has one cell left.
6. Uncover **row 3, column 1**. It is butter.
7. Teal still has two cells. The one in row 1, column 3 touches both remaining gold cells, so gold would have nowhere to go. Mark that teal cell. The other teal cell is forced.
8. Uncover **row 2, column 3**. It is teal.
9. Uncover **row 4, column 4**. It is the last open cell in column 4, and it is rose.
10. Uncover **row 1, column 5**. It is the last open cell in column 5, and it is gold.

## Level 2 — The Challenge

Butter is the block at the top left. Teal is the band across the top. Blue is the block on the left of row 3. Gold is the right edge. Rose is the shape in the middle. Green fills the bottom row and reaches upward.

1. Row 6 is entirely green, and green also appears above it. The green eggplant is in row 6. Mark every green cell in rows 4 and 5.
2. Row 5 is now only rose. Mark every rose cell above row 5.
3. Row 4 is now only gold, in columns 5 and 6. Mark every gold cell above row 4.

Four what-if checks clear the rest of the top:

4. Teal in row 1, column 3 forces blue into row 2, column 1, and that blue cell touches both cells left in row 3. Mark the teal cell.
5. Teal in row 1, column 4 forces green into row 6, column 3 and butter into row 2, column 2. Blue then has no cell left. Mark that teal cell.
6. Blue in row 2, column 1 forces teal into row 3, column 5, and row 4 disappears. Mark the blue cell.
7. Teal in row 3, column 5 also wipes out row 4. Mark it.
8. Butter in row 2, column 2 forces that same teal cell and fails the same way. Mark the butter cell.
9. Teal in row 2, column 5 forces gold into row 4, column 6 and rose into row 5, column 4, then column 3 is empty. Mark that teal cell.
10. Gold in row 4, column 5 leaves row 5 with no cell. Mark it.

The board is now forced. Uncover these cells in order:

11. **Row 4, column 6** — gold, the last cell in row 4.
12. **Row 5, column 4** — rose, the last cell in row 5.
13. **Row 2, column 3** — butter, the last cell in column 3.
14. **Row 1, column 5** — teal, the last cell in column 5.
15. **Row 3, column 1** — blue, the last cell of that color.
16. **Row 6, column 2** — green, the last cell of that color.

## Level 3 — The Expert

Butter is the whole top row and also dips into rows 2 and 3. Blue is the tall shape on the left. Teal is the small shape near the top. Gold is the block on the right of the middle rows. Rose is the large lower-left shape. Lilac is the middle band. Coral is the thin strip on the right edge. Green fills most of the bottom.

1. Coral exists only in column 8. Mark every other cell in column 8.
2. Row 1 is entirely butter, and butter continues below it. Mark every butter cell outside row 1.
3. Gold is now only the three cells in column 7, on rows 4, 5, and 6. Mark the rest of column 7.

Row 2 now has two candidates: blue in column 3, and teal in column 5.

4. Butter in row 1, column 4 touches both of those cells, so row 2 would vanish. Mark it.
5. Butter in row 1, column 5 forces blue into row 2, column 3, then teal into row 3, column 6, rose into row 4, column 4, and gold into row 5, column 7. Row 6 is then empty. Mark that butter cell.
6. Butter in row 1, column 6 starts the same blue-and-teal chain and empties row 7. Mark it.
7. Teal in row 3, column 5 forces blue into row 2, column 3, gold into row 4, column 7, rose into row 5, column 4, and butter into row 1, column 1. Column 2 is then empty. Mark that teal cell.
8. Blue in row 2, column 3 now forces butter into row 1, column 1, teal into row 3, column 6, rose into row 4, column 4, gold into row 5, column 7, lilac into row 6, column 5, and coral into row 7, column 8. Row 8 is empty. Mark the blue cell.
9. Uncover **row 2, column 5**. It is the last cell in row 2, and it is teal.

Row 3 is now only blue. Mark every blue cell outside row 3.

10. Rose in row 4, column 3 touches both blue cells left in row 3. Mark it.
11. Rose in row 4, column 4 forces blue into row 3, column 2 and butter into row 1, column 1, then column 3 is empty. Mark it.
12. Lilac in row 4, column 6 forces gold into row 6, column 7 and coral into row 8, column 8. Green then has no home. Mark the lilac cell.
13. Uncover **row 4, column 7**. It is gold, the last cell in row 4.

Sweep the new row, column, color, and neighbors. Lilac is now only in row 6, so mark lilac cells outside that row. Row 5 is only rose, so mark rose cells outside row 5. Column 1 is only butter, column 2 is only blue, and column 3 is only rose. Mark those colors outside those columns.

Uncover the last cell of each remaining row:

14. **Row 1, column 1** — butter.
15. **Row 3, column 2** — blue.
16. **Row 5, column 3** — rose.
17. **Row 6, column 6** — lilac.
18. **Row 7, column 8** — coral.
19. **Row 8, column 4** — green.

## Level 4

Gold fills the top row and also sits in rows 2 and 3. Blue is the short strip on the right of rows 2, 3, and 4. Rose is the block in the upper middle. Teal runs down the left and into the lower middle. Lilac is the lower-left corner. Butter is the block at the lower right. Green is the bottom-right corner.

1. Blue exists only in column 7. Mark the other cells in column 7.
2. Green is now the single cell in row 7, column 6. Mark the rest of row 7, and mark the rest of column 6.
3. Row 1 is entirely gold, and gold continues below it. Mark every gold cell outside row 1.
4. Uncover **row 7, column 6**. It is green, the last cell in row 7.
5. Lilac is now only in column 1. Mark the other cells in column 1.

Row 2 is down to rose in columns 4 and 5, and blue in column 7.

6. Gold in row 1, column 4 forces blue into row 2, column 7, rose into row 3, column 5, and teal into row 4, column 2. The rose clears the butter in column 5, and the teal touches the last lilac in row 5. Row 5 is empty. Mark that gold cell.
7. Gold in row 1, column 5 is the same column as the butter in row 5. It also forces blue into row 2, column 7, rose into row 3, column 4, and teal into row 4, column 2, which removes the lilac and teal cells left in row 5. Mark that gold cell.
8. Rose in row 2, column 4 forces gold into row 1, column 2. That gold clears the teal in column 2, so blue is forced into row 3, column 7 and row 4 disappears. Mark that rose cell.
9. Rose in row 2, column 5 clears the butter in that column. Blue is forced into row 3, column 7, then teal into row 4, column 2, which removes every cell left in row 5. Mark that rose cell.
10. Uncover **row 2, column 7**. It is blue, the last cell in row 2.

Row 3 is now only rose, so mark every rose cell outside row 3. Row 4 is now only teal, so mark every teal cell outside row 4. Column 3 is now only gold, so mark the gold cell in row 1, column 2.

11. Uncover **row 1, column 3**. It is gold.
12. Uncover **row 4, column 2**. It is teal, and it touches the lilac in row 5, column 1. Row 5 is only butter.
13. Uncover **row 5, column 5**. It is butter. It clears the rose in column 5 and the butter it touches in row 6.
14. Uncover **row 3, column 4**. It is rose, the last cell in row 3.
15. Uncover **row 6, column 1**. It is lilac, the last cell in row 6.
